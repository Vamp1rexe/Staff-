# Staff++ Remastered (Community Update)

**Unofficial community update of Staff++ (StaffPlusPlus) for Minecraft 26.3.**
This is not the official version. All credit for the plugin goes to the original authors (Shortninja, Qball, Garagepoort).

Original plugin: https://modrinth.com/plugin/staff-plus-plus

## Download
`releases/staffplusplus-remastered-26.3.0.jar`

## What changed vs. the official 26.2.0
- Minecraft 26.3 / 26.3.x is recognised and runs on the 26.2 compatibility layer (`patches/VersionUtil.java`).
- Plugin version set to `26.3.0-community`.
- Nothing else was modified (plugin name stays `StaffPlusPlus`, so existing configs/data keep working).

## Notes
- 26.3 support relies on the 26.2 NMS/packet layer being unchanged. If a 26.3 server build changes those internals, please open an issue.
- Always back up your `plugins/StaffPlusPlus` folder before updating.
- Support for the original plugin: use the Modrinth page above.
